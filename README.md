# Student Clicker: контейнер + CI/CD + мониторинг

Кликер про студента, который идёт к PhD. Приложение простое. Главное здесь процесс: сборка, артефакт, деплой и метрики.

## Быстрый запуск из исходников (для проверки)

Нужны Docker и Docker Compose.

```bash
git clone <URL репозитория> && cd student-clicker
./bash.sh            # или: docker compose up --build
```

| Что | Адрес |
|---|---|
| Приложение (интерфейс) | http://localhost:5000 |
| Health check | http://localhost:5000/health |
| Метрики приложения | http://localhost:5000/metrics |
| Prometheus | http://localhost:9090 |
| Grafana (дашборд «Student Clicker») | http://localhost:3000 |

Grafana открывается без логина (режим просмотра). Вход админа: `admin` / `admin` (на сервере пароль меняется через `.env`).

## CI/CD: как это работает

1. **Исходники** лежат в git. Разработчик делает `git push` в ветку `main`.
2. **Сборка (CI).** Пайплайн ставит зависимости и запускает smoke-тест: `/health`, главная страница, клик, наличие метрик.
3. **Артефакт.** Пайплайн собирает Docker-образ и сохраняет его в реестре (GHCR или GitLab Registry) с двумя тегами: `latest` и хэш коммита. Хэш позволяет откатиться на любую версию.
4. **Деплой (CD).** Пайплайн заходит на сервер по SSH и запускает `scripts/deploy.sh`.
5. **На сервере.** `deploy.sh` скачивает новый образ из реестра, перезапускает контейнеры и проверяет `/health`. Если приложение не отвечает, скрипт завершается с ошибкой и показывает логи.
6. **Сохранение.** Данные лежат в Docker-томах: прогресс игры (`clicker_data`), метрики (`prom_data`), настройки Grafana (`grafana_data`). После деплоя и перезапуска они не теряются.

Изменить приложение просто: правим код, делаем push, через пару минут на сервере новая версия.

## Метрики

| Требование | Где смотреть |
|---|---|
| Health check | `/health`; `HEALTHCHECK` в Dockerfile (`docker ps` показывает `healthy`); панель «Health» в Grafana (метрика `up`) |
| Посещений в час | `increase(student_page_visits_total[1h])`; считает только заходы на главную страницу |
| Ресурсы потребляемые | CPU и память контейнера (cAdvisor); CPU хоста (node-exporter) |
| Ресурсы доступные | Память и диск хоста: доступно и всего (node-exporter) |
| Использование приложения | Клики, уровни, XP, запросы по endpoint, латентность |

## Настройка сервера (один раз)

1. Ubuntu-сервер с открытыми портами 22, 5000, 3000 (и 9090, если нужен Prometheus).
2. `./scripts/server-setup.sh <URL репозитория>` ставит Docker и клонирует проект.
3. Отредактировать `~/student-clicker/.env` (образ и пароль Grafana).
4. Если образ в реестре приватный, один раз выполнить `docker login ghcr.io`. Либо сделать пакет публичным.
5. В настройках репозитория добавить секреты: `SERVER_HOST`, `SERVER_USER`, `SERVER_SSH_KEY`.
